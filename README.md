# 因读 QuantWise · 量化与因子读书伴学

**因读**，取「读懂因子」之意。App 显示名为「因读」，英文名、仓库和原生工程名为 **QuantWise**；中文标语是「读懂因子，看懂市场」。

读量化和因子投资的书时，AI 带着整本书一节一节讲；讲到概念时，用真实的 A 股行情画图、在本地算因子给你举例。
QuantWise 以 [AShareSim](https://github.com/MathildaStacy/AShareSim) 为底座（保留它的全部提交历史和功能：真实行情、真实规则的模拟交易、学习路线、AI 助手），把 [Pagewise](https://github.com/MathildaStacy/Pagewise) 的伴读能力（导入解析、书的地图、按节讲解、引用跳回原文、闪卡复习）移植进来。

设计和进度见下文「QuantWise」一节；后面是继承自 AShareSim 的说明。

## QuantWise

当前正式版 **v1.10.2**：交易时段里准备股票池数据时，不再存下当天还没收盘的那根日线；以前盘中存下的那一根收盘后算过期、下次用到时重取，见 [v1.10.2 发布说明](docs/releases/v1.10.2.md)。v1.10.1 起，准备中证 500、中证 1000 的数据时先向东方财富取日线，取不到再用腾讯；成分按固定的随机顺序取，被行情接口限流停下时，已取全的那一段就是一个随机样本，够 150 只就先用它做因子检验，结果里写明「随机 N 只」，见 [v1.10.1 发布说明](docs/releases/v1.10.1.md)。v1.10.0 起，书里的双重排序表可以在沪深 300 上按书里的口径复现，并和书里的分组逐组对照（中证 500、中证 1000 也能用，准备数据可能要分几次）；AFML 的元标签法可以在真实日线上跑一遍。书页上的宽表固定行名，可以全屏横屏看；图、表、代码各有自己的菜单；英文书可以「中文为主」阅读，讲解步骤名也看得懂了。见 [v1.10.0 发布说明](docs/releases/v1.10.0.md)。v1.9.0 起，AI 讲解从某一段或某一句提问时带上块号、前后文和段里提到的图表公式，自己输入的问题带上读到哪；书内搜索按相关度排序，用中文也能搜英文书。用真实行情举例时，横截面结论直接在 A 股复现，并和书里的多空收益、t 值对照（可选市值加权）；回撤、大涨、波动最大的那段由工具在数据里找，盘中价不当收盘，个股涨跌附同期沪深 300。复现结果可以存进研究手记，见 [v1.9.0 发布说明](docs/releases/v1.9.0.md)。

桌面名称、启动页、通知、iOS 工程和原型已统一命名。Android 包名 `com.quantwise`、数据库与服务配置保持兼容，可直接覆盖 v1.0.0 及更早版本，保留已有数据。

- **书架和导入**：内置示例教材《因子投资入门》（5 章 19 节，自己写的短教材）；导入 Markdown、EPUB（本机解析）和 PDF（MinerU 精准解析，超过 200 页按页码范围自动分片，App 被杀后接着轮询）。
- **听讲**：每节在本机切成 1–5 步，点「开始讲」才请求 AI。讲解里的引用点开看原文；AI 自己补的推导、编的例子、工具算出的真实数据分别用不同底色标出；问到别的小节时走岔路，回到主线折叠成一行并记进那一节的笔记。
- **真实行情举例**：AI 调用 `plot_chart`（前复权日 K、均线、布林带、动量 / 波动 / 回撤 / RSI 副图、对比图）、`get_factor_values`、`factor_test`（分组回测 + Rank IC），图存在消息里，排在讲它的文字前面。图有整数价格刻度和月份横轴；讲到某段行情时黄色标出那段，前收、末日收盘、区间涨跌和副图两端值写在图上，和 AI 拿到的摘要同一份数。卡片里点一下或按住拖动看每一天，图滚出屏幕时小图钉在讲解页顶部，全屏有数据表。结论按 t 值和期数说。
- **读书模式**：宋体 / 黑体、16–22 号及两档行距可选，标题、正文和图注有独立层次；保留合并表格、图片比例、代码与公式。讲过的段落和当前这一步有标记；段落菜单支持解释、从这里开始讲、用真实行情举例和高亮，图表操作有独立入口。
- **扫描图表重绘**：图片下点「AI 清晰重绘」，由本节的图片模型识别后显示原生图表、流程图或文字表格；支持放大、原图对照、识别说明与本机缓存。曲线标明读图估值，无法可靠识别时保留原图。
- **讲解设置与记录**：讲解输入区可选模型、思考强度和联网搜索，按小节保存，和 AI 助手分开；改设置前提示要重建多少缓存，可以改回。网页资料单独标出并附来源。导航栏「讲解记录」按小节列出问过的内容，可搜索、按目录看，能新开一轮（旧的一轮只读保留）。聊得长了自动把较早的讲解整理成摘要。
- **中文对照**：读书页顶部切到「中文对照」，点「翻译本节」，或从段落菜单点「翻译这一段」。默认完整原段后接完整中文段，可切换逐句核对或「中文为主」（只显示译文，段旁「原文」展开英文）；两种语言跟随阅读排版。术语按内置术语表和这本书以前的译法统一，本节第一次出现时写成「元标签（meta-labeling）」；脚注、参考文献和中文书不算待译。已完成段落自动保存，再次打开不重复请求 AI；排版变化保留阅读位置。
- **小结、复习、笔记**：讲完一节 AI 起草摘要、卡点和闪卡，确认后保存；Leitner 5 盒复习、卡点清单；笔记导出 Markdown 和 Anki CSV。
- **个人量化研习**：按学习目标和时间安排今日任务，查阅 8 个核心概念并完成 16 道原创练习；错题自动进入待练清单。研究手记保留假设、验证方法、证据与书籍来源，配合四项实验自查；预览材料后启动 AI 陪练，周报与手记可导出 Markdown。
- **因子实验室**：示例池 / 自选 + 持仓 / 沪深 300 当前成分，7 个因子，调仓周期、分组和成本可调，和听讲里的 `factor_test` 同一套口径。
- AShareSim 的全部功能保留；AI 助手多了 4 个行情与因子工具：画图、因子排名、因子检验和元标签检验（共 40 个）。
- Android 包名 `com.quantwise`，可以和 AShareSim 同时安装，数据互不影响。

内置入门体验无需网络或 AI Key。自由问答需要自己的 AI 服务（「我的 → 供应商与模型」）；导入 PDF 时需要 MinerU Token（「我的 → 解析服务（MinerU）」）。

已发布安装包：[下载 v1.10.2 Android APK](https://github.com/MathildaStacy/QuantWise/releases/download/v1.10.2/QuantWise-v1.10.2-arm64.apk)，或查看 [Releases](https://github.com/MathildaStacy/QuantWise/releases)。

开发：和下面 AShareSim 的一样（`npm run check`、`npm run android`）。`npm install` 会把离线 MathJax 复制进 `android/app/src/main/assets/math/`。没有 AI Key 时可以在电脑上运行 `node scripts/mock-ai.cjs`，再在调试版「我的 → 调试页 → 接本地模拟 AI」，用固定脚本走听讲流程。

# 继承自 AShareSim · A 股模拟交易与量化入门

用真实行情、按 A 股真实规则和真实税费做模拟交易的手机 App（先做 Android，iOS 后补）。
除了「入金是模拟的」之外，交易时间、集合竞价、T+1、涨跌停、价格笼子、交易单位、佣金 / 印花税 / 过户费 / 红利税都按交易所和券商的现行规则执行。

两个目标：

1. 练习炒股：了解 A 股市场、交易规则和每一笔费用是怎么来的。
2. 为个人量化打基础：对应 [量化学习路线](docs/research/quant-roadmap.html) 的阶段 0–3（规则、Python、统计、数据库），并提前做阶段 7（按真实规则记录模拟执行）。

## 安装（Android）

从 [Releases](https://github.com/MathildaStacy/QuantWise/releases) 下载 `QuantWise-v*-arm64.apk`，在手机上打开安装（第一次要允许浏览器或文件管理「安装未知应用」）。只打了 arm64-v8a，近几年的手机都是这个架构。

- 升级：直接安装新版本覆盖，账户、自选和设置都保留（每个版本用同一个签名）。
- 小米 HyperOS：装好后按「我的 → 后台跟踪与省电」把省电策略设为无限制、打开自启动，否则挂单时后台跟踪会被系统停掉。

## 开发

```bash
nvm use            # Node 24
npm install
npm run check      # eslint + tsc + jest
npm test -- __tests__/engine   # 只跑引擎测试
npm run android    # 需要 Android SDK；iOS 后补
```

发布版 APK：`cd android && ./gradlew :app:assembleRelease -PreactNativeArchitectures=arm64-v8a`，输出在 `android/app/build/outputs/apk/release/`。发布版和调试版都用仓库里的 `android/app/debug.keystore` 签名，不用另外保管密钥，任何机器打出来的包都能覆盖安装。

## 技术栈

沿用 NovelCreationPartner 的组合：React Native 0.87 + TypeScript、react-navigation 7、zustand、op-sqlite（本地行情库和账户账本）、react-native-svg（K 线 / 分时图）、lucide 图标；M4 加 react-native-keychain（AI Key）。
本地优先，没有后端：行情直接请求腾讯行情接口（ETF 排行用新浪，分红送配用东方财富），AI 直接用你自己的 Base URL + API Key，支持 OpenAI Responses 和 Anthropic Messages 两种协议。
