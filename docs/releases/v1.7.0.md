# 因读 · QuantWise v1.7.0 · 连续阅读、中文对照与讲解体验

读书时调整排版、查看导读和核对译文后，继续留在对应原文位置；读完一节可以直接进入下一节。AI 讲解将步骤、上下文和工具明细收进按需展开的面板，让原文与讲解保留更多阅读空间。

## 本次更新

- **连续阅读**：工具栏显示当前 PDF 物理页，点按打开对应原页；节末新增上一节／下一节及标题，保存阅读位置并沿用中文对照选择。
- **排版与导读**：排版设置、对照分组和本节导读使用可滚动底部面板。排版有中英文实时预览，对照工具栏可直接切换按段阅读与逐句核对。
- **阅读位置**：切换原文、中文对照、对照分组和字号时，按原文位置保留阅读锚点；新的段落跳转优先于旧的重排位置。
- **翻译与恢复**：中文正文夹带外文术语时不再重复翻译。进度入口优先定位当前翻译段或失败段，支持单段翻译与重试；本地译文未读到时准确提示并可重读缓存，保留已完成译文。
- **引用核对**：先显示命中的原段，前后文按需展开；切换引用时回到顶部，不再将尚未加载的引用误显示成第一段。
- **讲解操作**：完整步骤和其他快捷讲解方式放进独立面板，常驻主操作、看原文和更多入口。上下文先显示小节标题、学习进度和模型偏好，请求与用量明细按需展开。
- **对话阅读**：成功的工具记录默认折叠，失败仍直接可见；展开记录、来源和岔路时保留当前视口。图表、检查题和小结保持原有顺序，钉住的小图按自身高度占位，修复遮挡讲解的问题。
