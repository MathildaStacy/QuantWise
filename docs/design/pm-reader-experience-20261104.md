# 书页、中文对照、AI 讲解与讲解行情图：PM 走查第二轮

2026-11-04，`codex/pm-reader-experience`。承接 Codex 会话「作为 PM 再看书页、翻译页和 AI 对话讲解，列出 10 点并优化」（列出 10 点后中断，部分改动未接入），以及排在其后的「AI 结合真实行情图讲解时，再为学习者找 5 处优化」。上一轮见 [reader-lecture-polish-20261103.md](reader-lecture-polish-20261103.md)，行情图设计见 [ai-lecture-charts.md](ai-lecture-charts.md)。

## 一、书页、翻译与讲解（10 项）

| # | 体验问题 | 优化 |
| --- | --- | --- |
| 1 | 读到一半想换节，只能退回书架或逐节翻 | 读书工具栏加「目录」：可搜索的全书小节列表，打开时停在当前小节，标出正在阅读 / 已学完和原页；讲解生成中只能看、不能换节。 |
| 2 | 段落菜单在大字号下超出屏幕；公式段的预览是原始 TeX | 菜单内容可滚动；公式段按正文渲染，长段落截到 320 字。 |
| 3 | 宽公式、表格、代码被截断，看不出能横向滑动 | `HorizontalReading`：内容超宽时下方写「向左滑动查看完整公式 / 表格 / 代码」，滑到中间、末尾时换说法；读屏标签带「可左右滑动」。公式整体仍读作「公式：TeX」。 |
| 4 | 点「翻译本节」直接开始，不知道要译多少、发了什么、会不会计费 | 先弹确认面板：待译段数、跳过已保存的段数、发送内容和计费说明，按钮写明「开始翻译 N 段 / 翻译剩余 N 段」。翻译栏下多一行状态：还剩几段、已译内容可离线读、全部译完已保存在本机。 |
| 5 | 每个未译段下都写「尚无译文」，满屏噪音 | 只在读取中、正在翻译、翻译失败、缓存读取失败时写状态；其余段只留「翻译此段」。 |
| 6 | 从原文段落发起的讲解，对话里看不出问的是哪段 | 问题上方显示「提问原文 · 3.1 ¶2」和前三行原文，点开回到原文预览。存在 `MessageUi.studySource`，旧消息没有就不显示。 |
| 7 | 发出问题后输入框不清空，要等回答成功 | 发送即清空；没问完的问题留在重试区（`pending`），不会丢。 |
| 8 | 键盘弹出后快捷操作和输入框占掉大半屏 | 键盘打开时收起快捷操作行。 |
| 9 | 失败只写错误，看不到原问题，也不能改了再问 | 重试区分开写原问题和错误原因；自己输入的问题可以「修改后再问」（放回输入框并聚焦）；「稍后再问」在输入框为空时把问题放回草稿。 |
| 10 | 生成状态写在对话末尾，随对话滚走；停止只是一个方块图标 | 生成中在输入框上方固定一行：转圈、当前状态（思考中 / 正在调用 plot_chart…）、「停止」文字按钮。 |

走查中另外发现并修复：带编号的独立公式（`\tag{1.1}`，MinerU 解析的 PDF 里很常见）MathJax 会留出整行宽度、公式居中，窄屏第一眼只看到一大片空白和「向左滑动」提示。现在编号拿出来写在公式右边（`splitTag`），公式正常居中显示。

## 二、讲解里的真实行情图（5 项）

| # | 学习者遇到的问题 | 优化 |
| --- | --- | --- |
| 1 | 从原文段落点「用真实行情举例」，模型常不画图或不标区间 | `realBlock` 的问题和听讲里的「用真实行情举例」一致：要求 plot_chart，讲到哪段行情用 focus 标出，数字以工具结果为准。 |
| 2 | 点图看某一天，只有当日涨跌，看不出离区间起点走了多少；讲解却常说「前半段跌得最急」 | 区间里的那天读数加「较前收 ±x%」（新股写「较首日」），和图下区间读数同一个基数。 |
| 3 | 在图上找到想问的一天，只能自己把日期和数字敲进输入框 | 讲解里的图卡点中一天后出现「问这一天」：把图名和这一天的读数放进输入框并聚焦，接着写问题；换一天时替换上一天的读数，保留已写的问题。讲解记录、助手里的图不出这个按钮。 |
| 4 | 新手看不懂副图：动量柱、回撤、RSI、前复权、空心点分别什么意思 | 图卡页脚加「怎么看」，展开后按这张图实际有的元素讲读法（`howToRead`）：收盘线和前复权、黄色区间、前收与区间末日空心点、标注日、均线、布林带、各副图的读法、红涨绿跌。口径公式仍在全屏的「怎么算的」。 |
| 5 | 模型没调行情工具时（不支持工具或跳过了工具），凭记忆写的数也显示成「真实行情」 | 这一问及之前整段对话都没有成功调用过行情、因子工具时，`[[real]]` 块改成「行情未核对」提醒样式，并说明可点「用真实行情举例」让 AI 现算。讲解页和讲解记录一致。 |
