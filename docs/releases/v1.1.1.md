# 因读 · QuantWise v1.1.1 · PDF 解析修复

改善书籍导入后的内容保留与目录结构，减少脚注遗漏、目录行和附录题解被误当作正文章节的问题。

## 本次更新

- PDF 默认开启 OCR，用户仍可关闭；切换模型保留选择。已有文字层的书也可能存在负号、变量和公式符号错误。
- 保留页脚注释、边注和嵌套文本；六本真实书籍的回放恢复了此前无法在正文找到的 776 条脚注/边注文本。
- 改进目录页、图注、Part、章首页眉、附录答案和书后注释的识别；超过三层的标题仍保留在正文。
- 检测到页面没有独立可读内容时，从本机 PDF 生成原页图像供核对，并按原页长宽比显示。跨页合并不再被直接描述为 OCR 失败。
- Token 过期、额度不足时保存暂停原因，继续解析可复用已接受的任务和已完成分片。

## 安装与升级

附件 `QuantWise-v1.1.1-arm64.apk` 支持 Android `arm64-v8a`，包名 `com.quantwise`，versionCode `5`，沿用现有签名。无需卸载；本次不新增数据库迁移，不重建已导入书籍和学习记录。

## 验证与限制

- 迁移回归：61 个套件、747 项测试通过，包含六本书共 2,879 页、18 个真实 MinerU 分片的本地回放；TypeScript 通过，ESLint 仅有 2 条原有警告。4 项需凭据的 AI live 测试未运行。
- Android arm64 Debug 编译通过；发布版本另构建 Release APK 并检查签名及版本。
- 六本书的专项 App 阅读验收正在独立会话中进行，本次不宣称已完成所有原页、公式或 AI 回答的人工核对。
- 默认 OCR 仅影响新导入。已有结果中的负号、变量、公式编号和双栏顺序错误仍需核对；原页图像不等于可检索文字，跨页合并块的引用定位仍有限制。
- 本次发布 Android；iOS 未专项验证。
