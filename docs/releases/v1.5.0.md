# 因读 · QuantWise v1.5.0 · 电子书排版与扫描图表重绘

正文、中文译文和复杂图表按电子书阅读方式排版；中文扫描书中的图表可由 AI 识别成结构化数据，再显示为清晰的原生图表与文字。

## 本次更新

- **阅读排版**：宋体 / 黑体、16 / 18 / 20 / 22 号和标准 / 宽松行距可选；标题、正文、译文、图注与表格使用相应字体层次，设置自动保存。
- **连续中英对照**：默认完整原文段落后接中文段落，可切换逐句核对；复用已有译文，重排与重新打开时保留阅读位置。
- **表格与复杂内容**：保留跨行跨列表头、表题和表注，长单元格完整换行，金额小数保持在同一行；宽表、代码和公式可横向查看，插图按原比例展示。
- **扫描图表清晰重绘**：图片下点「AI 清晰重绘」，使用本节配置的图片模型识别折线、柱状、散点、简单流程图或表格，再用原生矢量图和文字绘制。支持停止、重试、放大、原图对照和识别说明，完成后保存在本机，离线重开可直接阅读。
- **估读与核对**：曲线始终标注「AI 近似重绘 · 读图估值」，可展开估读数据；扫描表格标注「待核对」。看不清或不支持的复杂图保留原图并解释原因。
- **图表操作**：引用、解释、高亮和 PDF 原页入口放在独立按钮中，横滑宽图和表格时不再触发段落菜单。

## 安装与升级

下载附件 `QuantWise-v1.5.0-arm64.apk` 直接覆盖安装。包名 `com.quantwise`，versionCode `12`、versionName `1.5.0`，沿用现有签名；无需卸载。

本次不增加数据库迁移，保留书籍、阅读位置、笔记、译文、学习记录、AI 配置和模拟账户。重绘按图主动发起，需要在「我的 → 供应商与模型」配置支持图片的模型；不会自动请求整本书的图表。

## 验证

- 全量 ESLint、TypeScript 及 832 项测试通过，保留两条既有测试 lint 警告，4 项既有 live 测试跳过。真实解析语料回归覆盖六本书的 193 个 HTML 表格，其中 60 个含合并单元格。
- 六本真实书原文和中文对照走查；真实模型翻译验证 6 段 / 33 个句对。《因子投资：方法与实践》《打开量化投资的黑箱》共 5 个真实图表样本验证，覆盖柱状图、均线图、密集折线、流程图和扫描现金流量表。
- Android 手机约 411dp 标准字号及 360dp / 1.3 倍字体下验证阅读、图表放大与原图对照、宽表横滑、排版设置和冷启动缓存复用。
- 曲线属于扫描图估读，无法恢复原始完整数据；本轮不是整书逐图精度认证。iOS 同步版本号，本次交付 Android arm64 安装包。
