# 书页、中文对照、AI 讲解：上下文检索与量化实战（PM 走查第三轮，14 项）

2026-11-04，分支 `feat/lecture-retrieval-practice`。上一轮见 [pm-reader-experience-20261104.md](pm-reader-experience-20261104.md)，行情图设计见 [ai-lecture-charts.md](ai-lecture-charts.md)。

这一轮按用户要求把重点放在「量化讲解实战」：讲解拿到的上下文对不对、够不够（选段、提问位置、书内检索），以及 AI 用真实行情和因子检验举例时能不能真的说明书里的结论。走查用 `QuantWise_Ebook_20261103` 模拟器上的 6 本真实书（《因子投资：方法与实践》、AFML、ISLP、《机器学习实战》、《打开量化投资的黑箱》、利率书）和示例教材，模型是 `gpt-6.1-sol`（xcpcai 中转），另用一个本地录制模型记下请求原文。

## 2. 选段与提问位置（第 7–10 项）

`study/selection.ts`：`refsIn` 认「图 / 表 / 式 / 公式 / 代码片段 / 第 x 节 / 第 x 章」和「Figure / Fig. / Exhibit / Table / Snippet / Listing / Equation / Eq. / Section / Chapter」后面的编号；`resolveRefs` 只认图注、表题开头（「如图3.20所示」那样的提及不算）和带 `\tag{}` 或末尾编号的公式，找不到就不附，不猜。表题单独一段时连同下一块表格一起附上。附了原文的别的小节的块记在 `studySource.refs`，`loadedOf` 把它们算作可引用。

`<selected_block>` 和 `<reading_position>` 都写在每次提问的 `<study_state>` 后面，不进缓存前缀；讲解协议第 2 条说明它们的用法。

## 3. 书内检索（第 11–13 项）

打分：每个概念的几种写法合计词频，BM25（k1 = 1.2、b = 0.5，idf 用全书块数），小节标题命中按 1.2 倍 idf 加分，乘以「命中概念数 / 概念数」的平方；目录、前言、参考文献、索引 × 0.25，像参考文献条目的块 × 0.4，当前小节 × 0.7。候选最多 600 块，另加标题命中但正文没提到的小节的前两块、已保存译文命中的块。

## 4. 真实行情与因子检验（第 1–6 项）

- `find`（`quant/charts.ts` 的 `findEpisode`）：回撤和涨幅的区间从峰 / 谷的下一个交易日开始，区间涨跌的基数正好是峰 / 谷那天，和找到的值一致；波动用 20 日日收益标准差 × √250。
- 同期沪深 300（`benchFocus`）：基数日和个股区间读数是同一天，基准那天没数据时这段为 null；沪深 300 自己画图时不取。
- 盘中：`openToday()` 在北京时间 15:00 前返回今天；价格图和对比图最后一根是今天时记 `live`。
- 多空 t 值：每期多空收益（扣费后，和净值同一份）的均值 / (标准差 / √期数)。
