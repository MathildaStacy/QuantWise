# 因读 · QuantWise v1.8.0 · 目录换节、讲解状态与读懂行情图

读书时可以从目录直接换节，公式、表格和代码超出屏幕时有提示，带编号的公式不再显示成一片空白。AI 讲解里提问不再丢、生成和停止一直看得见；讲解里的行情图多了读图说明，图上看到哪天就能带着那天的数去问。

## 本次更新

- **目录换节**：读书工具栏新增「目录」，按原书顺序列出全部小节，可按标题或编号搜索，打开时停在当前小节，标出正在阅读、已学完和原页；讲解生成中只能查看、不能换节。
- **公式与宽内容**：宽公式、表格和代码超出屏幕时，下方提示可以左右滑动；带编号的独立公式（如 `\tag{1.1}`）编号写在公式右边，公式正常居中显示。段落菜单可以滚动，公式段按正文渲染。
- **翻译前说清楚**：点「翻译本节」先显示待译段数、跳过的已保存段数、发送内容和计费说明，再开始；翻译栏下写明还剩几段、译文已保存在本机。未译的段落不再逐段写「尚无译文」，只在翻译中、失败或读取失败时提示。
- **讲解提问**：从原文某一段发起的讲解，对话里在问题上方显示那一段，点开回到原文。发送即清空输入框，没问完的问题留在重试区，能看到原问题和失败原因，自己输入的问题可以修改后再问。
- **讲解进行中**：生成状态和「停止」按钮固定在输入框上方，不随对话滚走；打字时收起快捷操作，给讲解留出空间。
- **读懂行情图**：图卡新增「怎么看」，按这张图上实际有的内容讲读法（收盘线与前复权、黄色区间、前收与区间末日、均线、各种副图、红涨绿跌）。点图看某一天时，区间里的日子另写较前收涨跌；在讲解里点「问这一天」，这一天的读数会带进输入框，接着写问题即可。
- **真实数据更可信**：从原文段落发起「用真实行情举例」时同样要求画图并标出讲到的那段。对话里还没有成功调用过行情、因子工具时，讲解中的「真实行情」改标「行情未核对」，提醒数字可能不准。
