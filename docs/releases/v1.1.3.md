# 因读 · QuantWise v1.1.3 · 修复书籍导入失败

修复从系统文件选择器导入中文、带空格或长文件名的书籍时出现的 `ENOENT`（找不到文件）和 `ENAMETOOLONG`（文件名过长）。

## 本次更新

- 正确解码文件选择器返回的本地 URI，避免把 `%E5…`、`%20` 等编码当成实际文件名读取；百分号、加号和 `#` 等字符也能正确处理。
- 临时副本使用短文件名，每次导入仍有独立目录；书架和导入信息保留原始文件名，同名书不会覆盖彼此的临时文件。
- 包含 v1.1.2 的阅读改进：本地 PDF 原页查看器支持跳页、缩放与旋转；书架自动刷新解析状态，改善目录层级、大字号、脚注和行内公式显示。详见 [v1.1.2 说明](v1.1.2.md)。

## 安装与升级

下载附件 `QuantWise-v1.1.3-arm64.apk` 覆盖安装。Android 包名 `com.quantwise`、versionCode `7`、versionName `1.1.3`，沿用现有签名；不新增数据库迁移，保留已有书籍、学习进度、笔记和模拟账户。

安装后可使用原文件名重新选择此前失败的书籍，无需为了这项修复手动改名。PDF 上传仍需在解析设置页确认。

## 验证与限制

- 使用真实本地文件的回归覆盖截图中的两种书名、超长名称、中文路径、空格、百分号、同名文件及 Markdown 导入；修复前 6 项均失败，修复后全部通过。
- 全量质量检查及 Android arm64 Release 构建结果、APK 签名和版本核验附在 GitHub Release。
- 六本真实 PDF 的阅读、原页及伴读验收沿用 [v1.1.2 验收报告](../design/reading-acceptance-20261102.md)。本次导入修复不改变既有 OCR 结果；负号、变量、公式编号和跨页引用定位仍需按原页核对。
- iOS 版本号同步，本次发布 Android 安装包。
