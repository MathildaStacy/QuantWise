# 因读 · QuantWise v1.3.0 · AI 讲解设置、讲解记录与长对话整理

AI 讲解可以单独选用哪个模型、想多深、要不要联网，不再跟着 AI 助手当前的对话走；问过的讲解有了列表；同一节聊得很长时自动整理，不再超出上下文。

## 本次更新

- **讲解自己的模型、思考和搜索**：讲解输入区和助手同一套控件（模型名、联网搜索、思考强度），按小节保存；新小节沿用讲解最近一次的选择，搜索默认关。在助手里换模型不再影响讲解，讲解的缓存也不会因此失效。逐句翻译改用这一节讲解的模型。
- **改设置前先看代价**：换模型、调思考或开关搜索后，输入区上方提示下一次要重建多少缓存，可以「改回」。发送后在这一问前插一条分隔线写明新设置。每一问下方可展开看模型、来源和用量（含缓存读写）。
- **讲解里联网搜索**：支持 Anthropic、OpenAI Responses、Kimi 等可搜索的模型。网页内容放在单独的「网页资料」底色块里，附可点的来源；书中引用仍只指向读过的原文，网页资料不进小结和闪卡。问到新闻、最新研究而搜索关着时，回答下方给「开启搜索并重问」。
- **讲解记录**：讲解页右上角、书的地图和「对话列表 → 读书讲解」都能打开。按小节一行显示进度、最后一个问题和设置，可搜索、按目录看。长按可继续讲解、新开一轮（旧的一轮只读保留，学习进度、笔记、闪卡和卡点不变）、导出 Markdown、删除。
- **长对话自动整理**：回答结束后上下文超过整理线时，把较早的讲解整理成摘要，保留最近 3 问原文；快到上下文上限时先整理再问。长小节分段读取，书内搜索只返回命中处前后；一问之内读取过多时截断结果、让 AI 根据已读内容回答。回答因篇幅被截断时可点「接着讲」。
- **兼容与缓存修复**（助手和讲解共用）：整理请求保留工具定义，Anthropic 不再因此丢掉对话缓存；整理后保留的回答不再回放旧思考块，避免较新的 Anthropic 模型报 400；「解释这次结果」保留工具定义；讲解和助手的 `prompt_cache_key` 分开。Codex 模型只给官方支持的思考档位，搜索能力按未知处理，用在 Chat Completions 协议下时提示改用 OpenAI Responses。

## 安装与升级

下载附件 `QuantWise-v1.3.0-arm64.apk` 直接覆盖安装。包名 `com.quantwise`，versionCode `10`、versionName `1.3.0`，沿用现有签名。数据库升级到第 10 版（讲解对话增加归档时间），已有书籍、笔记、学习记录、译文、AI 配置及模拟账户保留；升级后不能再装回旧版本打开同一份数据。

已有的讲解对话第一次打开时，按最后一次回答用的模型认领设置；那个模型停用了就用讲解最近一次的选择。
