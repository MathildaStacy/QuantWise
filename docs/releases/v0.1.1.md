# QuantWise v0.1.1 · 公式与图表显示修复

本补丁收录 v0.1.0 后的两项显示修复，补齐真实模型和 MinerU 的验收记录。原有书架、伴读、复习、因子实验室和 AShareSim 功能保持兼容。

## 修复

- MinerU 解析会在 TeX 的记号之间插入空格。行内公式现在忽略数学模式的源空白，按运算符补空格，例如 `0 . 8 \times 1 2 = 9 . 6` 显示为 `0.8 × 12 = 9.6`；保留文本命令中的词间空格，并覆盖上下标、负数、分式等 11 个回归断言。对应提交 `af26f8a`。
- 行情及因子图表的坐标值、极值标签增加背景色描边，压在折线和柱形上时仍清晰可读。对应提交 `b6d21e1`。
- Android 版本改为 `0.1.1`，versionCode 从 1 增至 2，可覆盖安装 v0.1.0，保留书籍、学习进度、笔记和服务配置；没有数据库迁移。

## 验收

真实服务验收沿用发布前 Claude Desktop 会话的独立 `QuantWise_Test` 模拟器记录：

- 真实模型 `deepseek-v4.1-flash-1017` 完成 3.1 动量讲解、行情举例、因子检验、检查题、小结及闪卡保存；保存后转到 3.2。5 个引用的涨跌幅与腾讯前复权日线复算一致。
- 20 日动量检验 IC 约 +0.051、t 约 1.35；12-1 月动量 IC 约 −0.049、t 约 −0.78。模型没有把不显著结果表述为确定有效，并提示了当前成分股的幸存者偏差。
- MinerU 连接成功，5 页示例 PDF 导入后分为 10 节，保留页码和表格；修复后的行内公式与图表标签在 release APK 上确认。独立公式的离线 MathJax 渲染正常。

本次发布验证：

- `npm run check` 通过：57 个 Jest 套件、708 项测试全部通过；TypeScript 无错误；ESLint 无错误，保留 2 条原有测试文件警告。
- `:app:assembleRelease -PreactNativeArchitectures=arm64-v8a --no-daemon --max-workers=2` 构建成功；`apksigner verify` 通过，APK 包名、版本和架构核对为 `com.quantwise` / `0.1.1` / versionCode 2 / arm64-v8a。
- 在独立 `QuantWise_Test` 上执行覆盖安装成功，首次安装时间保留，安装版本由 0.1.0 升到 0.1.1。本次设备验证覆盖安装和包信息；业务代码未变，界面回归沿用上述原会话记录。
- 发布提交需通过 GitHub Actions 的 Quality 和 Android build 后再打 tag；iOS 按项目约定跳过。

## 已知限制

- OCR 仍可能识错或漏掉内容（实测有中文句号识别成 `0`、漏掉 `BR`）；本补丁只修复显示空格，不推测原文。
- PDF 只支持重排阅读和页码引用，不显示原版页；单文件上限 200 MB。导入书籍暂不支持改名。
- 因子数据最多 750 根前复权日线；沪深 300 使用当前成分，小市值和低换手使用当前股本近似。
- 仅发布 Android arm64 预发布包；iOS 未验证。

## 安装

下载 `QuantWise-v0.1.1-arm64.apk` 覆盖安装。包名 `com.quantwise`，沿用 v0.1.0 的仓库签名，可与 AShareSim 同时安装。`SHA256SUMS.txt` 用于核对下载文件。
