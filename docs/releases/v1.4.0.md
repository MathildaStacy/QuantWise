# 因读 · QuantWise v1.4.0 · 个人量化研习

新增「学习 → 研习」，让读书、基础练习和策略研究接起来：安排今天的学习，独立作答找出薄弱点，再把书中的观点写成可验证的研究假设。

## 本次更新

- **个人学习计划**：选择基础理解、因子实践或研究习惯，安排每次 10 / 20 / 40 分钟、每周 3 / 5 / 7 天，可关联书架中的书。调整目标会保留历史作答与手记。
- **今日任务**：按计划时间、到期闪卡、错题与研究记录给出可直接打开的学习任务。
- **量化知识地图**：8 个核心概念，支持中文、英文与公式关键词搜索、收藏、先修概念导航及内置教材原文跳转。
- **基础诊断与练习**：16 道原创题；诊断每次覆盖 8 个概念，优先选择未答题；提交后展示答案和推导。
- **错题再练**：最近答错的题自动进入待练列表，重新答对后移出，历史作答保留。
- **研究手记**：记录假设、验证方法、观察证据、结论和下一步，可关联概念及真实书籍小节；未保存返回时提示，删书后仍保留研究与来源文字。
- **实验质量自查**：分别记录信息与交易时点、历史股票池、费用与成交约束、样本外与多重尝试的检查依据。填写情况表示已记录依据，不代表系统已验证实验。
- **AI 陪练**：先编辑问题、预览所附概念或研究材料，再主动发送到既有 AI 助手；复用当前供应商与模型配置。
- **学习周报与导出**：按本地日期统计真实作答、活跃天数、薄弱点及研究记录；周报与手记可导出 Markdown，方便在电脑上继续研究。

## 安装与升级

下载附件 `QuantWise-v1.4.0-arm64.apk` 直接覆盖安装。包名 `com.quantwise`，versionCode `11`、versionName `1.4.0`，沿用现有签名。

数据库升级到第 11 版，新增独立研习数据表，保留已有书籍、笔记、译文、AI 配置、学习记录及模拟账户。升级后不要用旧版本打开已升级的同一份数据。

计划、知识地图、诊断、错题、手记与周报可离线使用；AI 陪练需要在「我的 → 供应商与模型」配置自己的服务。
