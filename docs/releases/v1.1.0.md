# 因读 · QuantWise v1.1.0 · 学习体验升级

第一次打开即可离线体验动量概念、例子和检查题；学习中断后能接着读、接着问，因子实验和小结保存也更容易理解与完成。

## 本次更新

- **先体验，再连接 AI**：无网络、无 Key 可完成入门体验；供应商配置优先展示 Key 与模型，保存后可返回原小节与问题。
- **中断后接着学**：保存阅读位置、讲解位置和问题草稿；上翻后可回到最新，跨天续学保留回顾；失败或停止不会提前推进已讲步骤，原问题可重试。
- **看懂同一次实验**：结论与证据置前，修改参数后确认应用；AI 解读使用当前结果快照，明确分组顺序和扣费口径，避免重新计算后混入另一份结果。
- **保存后放心结束**：小结先读后编辑，闪卡可选择保存；支持保存结束或继续下一节，区分没有闪卡、未到期和今日已完成。
- **导航与界面整理**：底部为「学习 / 自选 / 行情 / 模拟交易 / 我的」；学习设置置前，常用控件达到 48dp，改善大字号换行、键盘避让、安全区和图表读数。
- **修复**：模拟入金后账户页面立即刷新；书架与书的地图使用一致的续学小节；检查题解析正确显示例子、公式与可点击原文引用。

## 安装与升级

下载本页附件 **`QuantWise-v1.1.0-arm64.apk`** 覆盖安装，支持 Android `arm64-v8a`。版本 `1.1.0`，versionCode `4`，包名 `com.quantwise`。

沿用原版本签名，不新增数据库迁移；可保留书籍、学习进度、笔记、模拟账户和服务配置。无需先卸载。安装包不包含 AI Key；自由问答需在「我的 → 供应商与模型」配置自己的服务，PDF 导入还需 MinerU Token。

## 已知限制

- 本次仅发布 Android；iOS、实体机性能和完整 TalkBack 尚未专项验证。
- PDF 使用重排阅读，不显示原版页；OCR 可能识错或漏字，本次未重复验证 PDF 上传解析全链路。
- 因子数据最多 750 根前复权日线，使用当前成分存在幸存者偏差；本次样本结果不代表未来收益。
- AI 验收覆盖有限场景，回复质量仍受模型与服务状态影响。
