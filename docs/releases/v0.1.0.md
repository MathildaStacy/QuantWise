# QuantWise v0.1.0 · 读书伴学第一版

QuantWise 以 AShareSim v0.10.0 为底座（全部功能和提交历史保留），加入 Pagewise 的伴读能力和新的行情图表、因子工具。读量化和因子投资的书时，AI 一节一节讲，讲到概念时用真实的 A 股行情画图、在本机算因子举例。打开 App 默认是「学习 → 读书」。

## 新功能

- 书架和导入：内置示例教材《因子投资入门》（5 章 19 节，QuantWise 自己写的短教材）；导入 Markdown、EPUB（本机解析）和 PDF（MinerU 精准解析：超过 200 页按页码范围自动分片，每片的任务号存在本机，App 被杀后接着轮询、不重复上传）。同一个文件不会重复导入。
- 听讲：每节在本机切成 1–5 步（不调用模型），进来先看本节路线图，点「开始讲」或提问才请求 AI。讲解里的引用 `3.1 ¶2` 点开看原文，引用到本轮没读过的原文时显示「未核实」；AI 自己补的推导、编的例子、工具算出的真实数据分别用蓝、橙、青底色标出。问到别的小节走岔路，点「回到主线」折叠成一行，问答记进被问那一节的笔记（不请求模型）。快捷动作：懂了继续、用真实行情举例、这个因子在 A 股有效吗、考考我、换个说法、举个例子、跳过下一步。
- 真实行情图和因子检验：`plot_chart`（前复权日 K、均线、布林带、动量 / 波动 / 回撤 / RSI / 成交量副图、极值标注、几只证券起点 = 100 对比）、`get_factor_values`（某天股票池里的因子排名）、`factor_test`（分组回测 + Rank IC、ICIR、t 值、换手、扣费后多空收益）。图的数据存在消息里，历史对话打开时和当时一样；全屏看十字线读数和「怎么算的」。AI 助手也能用这 3 个工具（共 39 个）。
- 读书模式：重排显示原文（宋体），独立公式用离线 MathJax 渲染，行内公式转成文字；讲过的段落和当前这一步有标记；点段落可以解释、从这里开始讲、用真实行情举例、高亮。
- 本节小结和复习：讲完一节 AI 起草摘要、卡点和闪卡（没配 AI 时用本机草稿），改好再保存，进度移到下一节；Leitner 5 盒复习（1 / 3 / 7 / 15 / 30 天）、卡点清单（可以让 AI 重讲）；笔记导出 Markdown 和 Anki CSV。
- 因子实验室：示例池（25 只大盘股）、自选 + 持仓、沪深 300 当前成分（新浪取成分，「准备数据」下载约 3 年前复权日线）；7 个因子（20 / 60 日动量、12-1 月动量、20 日反转、20 日低波动、20 日低换手和小市值两个近似因子），调仓周期、分组、单边成本可调。
- 「我的」加了解析服务（MinerU Token 存 Keystore）、讲解偏好、因子实验室入口。

## 验证

- `npm run check`：ESLint 0 个错误（2 条警告是 AShareSim 原有的测试文件）、TypeScript 通过、Jest 57 个测试套件、708 项测试通过（AShareSim 原有 560 项全部保留）。GitHub Actions：Quality、Android build 通过。
- 因子引擎和原型对账：用原型同一份快照日线跑 20 日动量 / 60 日动量 / 20 日低波动 / 20 日反转，期数、Rank IC 均值、t 值、多空年化和换手与原型 `quant.js` 一致。
- 伴读运行时、导入流水线（Markdown、EPUB、PDF 分片 / 暂停续传 / 失败重试）、MinerU 客户端、EPUB 解析、MathJax 桥都有单测；新页面有渲染测试。
- Pixel 10 Pro 模拟器（Android 17，arm64）上装 release APK 走查：启动直接到「学习 → 读书」，示例教材在书架上；书的地图；3.1 听讲显示本节路线图（4 步）和「开始讲第 1 步」，进来不请求模型；读书模式的宋体正文和离线 MathJax 公式；没有配置 AI 时「读完这一节」用本机草稿，保存后进度移到 3.2；因子实验室在设备上从腾讯取 25 只股票 750 根前复权日线，算出 36 期的 Rank IC（+0.051，t 1.35，标「不显著」）、多空年化（扣费后 −10.4%）和三张图。
- 听讲里的 AI 讲解、引用、真实行情图卡片、检查题和小结草稿在 Jest 里用脚本化的模型走过完整流程（`__tests__/study/session.test.ts`、`__tests__/ui/studyScreens.test.tsx`），没有在设备上接真实模型跑。

## 已知限制和待验收

- 真实模型和 MinerU 没有用真实 Key / Token 跑过：模拟器上用的是本地模拟服务。请用你自己的 AI 服务和 MinerU Token 验收「听讲 → 真实行情举例 → 因子检验 → 小结」和一本 PDF 的导入。
- PDF 只有重排阅读，没有原版页和位置框；超过 200 MB 的 PDF 还不能解析。
- 沪深 300 用当前成分回测，有幸存者偏差；小市值、低换手用今天的股本往回推，是近似值。前复权日线最多 750 根（约 3 年）。
- 全文搜索用 LIKE，不分词。只做 Android；iOS 没有验证。

## 安装

下载 `QuantWise-v0.1.0-arm64.apk` 安装（只有 arm64-v8a）。包名 `com.quantwise`，和 AShareSim 可以同时安装，数据互不影响。用仓库里的 debug.keystore 签名（和 AShareSim 一样），以后的版本可以覆盖安装。`SHA256SUMS.txt` 用来核对下载文件。
