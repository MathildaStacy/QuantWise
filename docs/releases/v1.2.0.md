# 因读 · QuantWise v1.2.0 · AI 逐句中文对照

读外文教材时，可以在原文下直接查看简体中文译文，无需切到聊天页面反复对照。

## 本次更新

- 阅读顶部提供「原文 / 中文对照 / AI 讲解」三种视图。点「中文对照 → 翻译本节」开始，也可点一段原文选择「翻译这一段」。
- 每句原文下方紧跟对应译文；长句随屏幕宽度换行。正文、列表与图注支持翻译，纯中文、独立公式、代码、表格及 PDF 原页保留原样。
- 使用「供应商与模型」中的当前 AI 模型，兼容 Anthropic Messages、OpenAI Responses 和 Chat Completions。进入对照视图不会自动请求 AI。
- 按段显示进度，支持停止、失败重试和继续。完整段落自动保存到本机，重新打开可离线阅读；继续只补译未完成的段落。
- 原文来自本地书籍，译文按句子编号对齐；缺句、错号、空译文、数字或行内公式变动会提示重试。翻译不会推进讲解进度或写入讲解聊天；屏幕朗读包含完整原句和译文。
- 保留段落高亮、引用、PDF 原页和阅读位置。切换到原文、离开读书页会停止当前翻译。

## 安装与升级

下载附件 `QuantWise-v1.2.0-arm64.apk` 直接覆盖安装。包名 `com.quantwise`，versionCode `9`、versionName `1.2.0`，沿用现有签名。新增译文缓存表，已有书籍、笔记、学习记录、AI 配置及模拟账户保留。

初次翻译需要自己的 AI 服务和网络；已保存的译文无需网络。删除书籍或重新解析时，对应译文缓存随内容清理。
