# 扫描书图表清晰重绘验收

2026-11-03，`codex/ebook-reading`，承接 [电子书排版验收](ebook-reading-20261103.md)。用户要求继续兼容《因子投资：方法与实践》《打开量化投资的黑箱》两本中文扫描 PDF，把图表转换成清晰可读的电子书内容。

## 实际使用

在原文或中文对照阅读中，图片下方新增 **AI 清晰重绘**。点击后使用本节配置的图片模型识别当前图、图注和相邻文字，完成后默认显示重绘结果，再次打开直接读本机缓存。正文和已有 HTML 表格继续复用已完成的 MinerU 解析，不重传、不重解析全书。

| 内容 | 展示与边界 |
| --- | --- |
| 折线、柱状、散点图 | 模型输出坐标范围、单位、图例和估读点，应用用原生 SVG 绘制。保留实线/虚线/点线、原图标注和缺失段；始终显示「AI 近似重绘 · 读图估值」。 |
| 扫描表格 | 输出单元格文字，显示可选中文字的原生表格。空白保持空白，长文字完整换行，金额不拆小数；显示「AI 识别表格 · 待核对」。 |
| 简单结构/流程图 | 重绘节点、文字和箭头；双向关系保留两条边。文字跟随书籍字体和系统字号。 |
| 无法可靠识别、照片、多轴、复杂多面板/三维图 | 保留扫描图，并解释无法重绘的原因，可重试。 |

图表初始适配页面宽度，**放大图表**可展开宽图横向查看；**对照原图 / 查看重绘**随时切换。曲线可展开估读数据，识别说明中保留具体限制。图片识别可停止，离开阅读页会取消请求。图表与表格的引用、解释、高亮及 PDF 原页入口统一放在独立的 **图表操作**，避免横滑被段落点击抢走。

模型只返回 JSON，应用校验后绘制，不执行模型产生的 SVG 或代码。结果存在书籍目录的 `redrawn/<seq>.json`；版本、原图路径、图注和图片 SHA-256 一致才复用。使用现有供应商密钥与模型配置，支持 Responses、Chat Completions、Anthropic 三种图片协议，没有新增依赖或数据库迁移。

这是逐图按需转换。两本书当前有 **172 个图片块、115 个 HTML 表格块**；本轮没有自动转换全书，也没有把扫描曲线估读成原始行情或精确统计数据。

识别测试共 7 次模型请求（均线图补测标注一次，密集折线重试一次）。结构校验仅验证结果是否能正确渲染，不能证明数字和原书逐点一致。密集折线保留主要形态而非全部逐日波动；原图面积填充未复现，说明中披露。原书旧解析误并入图片块的「表 3.4 基准报告期」图注仍保留，未借重绘改写源文。
