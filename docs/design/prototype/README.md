# 原型源文件

`../prototype.html` 是由这里的文件拼出来的单文件原型，直接用浏览器打开即可（不联网）。
QuantWise 在 AShareSim 原型的基础上加了「读书伴学」：书架、导入与解析、书的地图、读书 ⇄ 听讲、真实行情图表卡、因子检验、岔路、本节小结、复习、笔记、因子实验室。

| 文件 | 内容 |
| --- | --- |
| `core.js` | 规则、费用、行情模拟、撮合、清算（对应 `docs/TRADING_RULES.md` 的简化实现） |
| `ui-base.js` | 路由、浮层、K 线 / 分时 / 折线图、时钟 |
| `ui-market.js` | 自选、行情、个股、搜索 |
| `ui-trade.js` | 交易、下单、撤单、持仓、委托、交割单、银证转账 |
| `ui-learn.js` | 学习路线：阶段 0/1/2/3/7、规则课、费用计算器、集合竞价演示、数据练习、账户分析、数据中心、模拟执行 |
| `ui-ai.js` | AI 助手：页面上下文、操作记录、对话列表与摘要、长期记忆、上下文查看页、服务配置；个股页多了「画出它的 20 日动量」 |
| `quant.js` | 因子引擎（动量、反转、低波动；分组回测、Rank IC、ICIR、换手）和图表卡片，用快照里的真实日线现算 |
| `ui-book.js` | Markdown → 章节和内容块、极简公式排版、书和学习记录的状态 |
| `ui-shelf.js` / `ui-shelf2.js` | 学习 Tab 的「读书 / 路线」、书架、导入、解析进度、书的地图、全文搜索、复习、笔记、解析服务和讲解偏好 |
| `ui-study.js` / `ui-study2.js` / `ui-study3.js` | 听讲：本节路线图、讲解脚本、引用校验和来源标记、真实行情举例、因子检验、岔路、检查题；读书模式、原文预览、「AI 现在看到了什么」、本节小结 |
| `ui-factor.js` | 因子实验室、全屏图表（十字线读数）、新页面的 AI 页面上下文 |
| `ui-me.js` | 我的、费率与交割单校准、原型控制台、启动 |
| `shell.html` | 页面骨架和样式 |
| `snapshot-2026-10-26.json` | 2026-10-26 11:30 从腾讯接口抓的快照、分时、日线（26 只个股约 250 个交易日，就是示例池） |

示例教材《因子投资入门》的正文在 `src/book/sample.ts`，`build.py` 从那里取，原型和 App 用同一份内容。

```bash
python3 build.py                                   # 生成 ../prototype.html
node rules-test.js snapshot-2026-10-26.json core.js # 费用 / 红利税 / 价格笼子 / 涨跌停自检
```

打开 `prototype.html#听讲 3.1`、`#因子实验室`、`#个股` 等可以直接跳到某个页面（名称见原型右侧控制台的「页面」列表）。

原型里只有 3.1 动量因子写了完整讲解；其他小节的讲解直接摘原文。AI 回答是本地脚本，但图表和因子检验的数字都是用真实日线现算的，文字里的结论按算出来的数写。
