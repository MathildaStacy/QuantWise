# 因读 · QuantWise v1.9.0 · 讲解的上下文检索与量化实战

AI 讲解拿到的上下文更准：从某一段或某一句提问时，带上块号、前后块和段里提到的图、表、公式；自己输入的问题带上读到了哪；书内搜索按相关度排，中英术语互通。用真实行情举例时按书里的结论选工具：横截面结论直接在 A 股复现，并和书里的数字逐项对照；回撤、大涨、波动最大的那段由工具在数据里找；盘中价不当收盘价，个股涨跌附同期沪深 300。复现结果可以存进研究手记。

## 本次更新

- **在 A 股复现书里的结论**：段落讲的是分组、多空、t 值、IC、月均收益这类横截面结论时，「用真实行情举例」改用因子检验按书里的口径跑，再和书里的数字对照；讲价格走势的段落才画行情图。这类段落的菜单多一项「在 A 股复现这个结论」。样本太小时，讲解会直接说「这次复现说明不了」。
- **和书里的分组表对照**：因子检验结果新增多空每期平均收益和它的 t 值。这是普通 t 值，书里多是 Newey-West，结果里会注明。新增市值加权：按调仓日总市值加权，市值由今天的股本往回推，结果里注明是近似。
- **让工具找那段行情**：讲回撤、暴涨、波动聚集时，行情图可以由工具在给定的日线里找峰到谷最深、谷到峰最大或 20 日波动最大的一段，并标成重点区间。摘要写明是在哪段数据里找到的日期，不再凭记忆写「9 月」。
- **盘中价不当收盘**：北京时间 15:00 前，最后一根 K 线是盘中数据。摘要会提醒模型不要说成收盘价，图脚写「11/4 为盘中价，未收盘」，区间读数标「盘中」。行情接口遇到 5xx、超时或断网时自动重试一次；还不行就让模型告诉你稍后再试，不凭记忆补数。
- **同期沪深 300**：有重点区间的个股价格图会多一行「同期沪深 300 −17.24% · 超额 −34.70 个百分点」，分得清是跟着大盘跌还是自己跌；基准取不到时只少这一行。
- **存进研究手记**：讲解里的分组净值图可以「存进研究手记」。书里的说法作假设，检验口径作方法，IC 和多空的 t 值作证据，来源写书名和小节，AI 讲解的要点放进结论里供你改写。草稿点「保存」才写入，没保存就离开时会提醒。
- **选段讲解带上下文**：从某一段提问时，问题写明块号，例如「[3.5.3#1]（p.168）」，原文开头截在句末。另附前后两块的块号，以及段里提到的图、表、公式、代码片段和小节：在本节的给块号，在别的小节的附原文，也可以引用。
- **只问其中一句**：段落菜单新增「只问其中一句（共 N 句）」，展开后逐句列出。选一句后可以解释这一句、用真实行情举例或在 A 股复现，整段作为背景。
- **读到哪、对照译文**：自己输入的问题会带上原文里最近读到的块，「这里为什么…」不用再说明是哪里。开着中文对照提问时，选段和读到的那段都附上已保存的译文，讲解用词和译文一致，译文有错会直接指出。
- **用你的股票举例**：讲解的学习状态附上自选和持仓（最多 8 只），真实行情举例优先从里面挑。
- **书内搜索按相关度排**：查询拆成几个概念，按 BM25 打分，小节标题命中加分。目录、前言、参考文献、索引和像参考文献条目的段落降权，当前小节标「已在上下文里」，每个小节最多 2 处，并先列「最相关的小节」。书里没出现的词会单独告诉模型。例如搜「动量」，结果从前言和第 1 章变成 3.5 动量因子各小节。
- **用中文搜英文书**：约 130 组量化、统计、机器学习术语中英对照，搜索时双向扩展，同时检索已保存的中文译文。例如在 AFML 里搜「三重屏障」命中 3.4，在 ISLP 里搜「岭回归」命中 6.2.1。
- **没问成的提问不重复发送**：API Key 失效等原因重试几次后，请求里不再重复同一个问题。对话里把连续几次失败折叠成一行「没问成 N 次」。
- **讲解步骤更好认**：脚注跟着前文，不再单独成一步。单独一段的表题和后面的表格（图）合成一步，标题用图注或表题。

## 版本与升级

源码标签 `v1.9.0`；Android 包名 `com.quantwise`，versionCode `16`、versionName `1.9.0`，沿用现有签名。可按 README 的发布版构建命令生成 arm64 APK，覆盖安装后保留已有数据。

本次没有数据库迁移，书籍、译文缓存、讲解对话、笔记、学习记录、研究手记、AI 配置和模拟账户都会保留。讲解协议和工具定义有改动，每个讲解对话升级后的第一次提问会重建一次提示缓存。iOS 工程同步版本号。
