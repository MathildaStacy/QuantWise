# 个人量化研习闭环

## 产品判断与边界

用户为个人量化学习者，需要同时读懂书、掌握基础、形成可复查的研究习惯。当前已有书籍导入、AI 逐节讲解、翻译、闪卡、章节笔记、A 股规则课、因子实验与模拟交易；缺少跨书的学习目标、量化概念诊断、客观错题记录以及从书中观点到实验结论的研究记录。

本轮在「学习」中增加「研习」分段，沿用暖白、墨蓝和原生列表。原有「读书 / 路线」保留。学习进度独立于模拟账户，离线可用；AI 陪练由用户主动启动，复用既有供应商和对话能力。

基线：`f79a605`。独立 worktree：`QuantWise-personal-learning`，分支：`codex/feature-personal-quant-learning`。已核对 Claude 的 `feat/lecture-chart-readability` 工作区：其范围是讲解提示词、股票/因子图表、讲解历史和相关测试。本轮不编辑这些文件，不改 AI 系统提示词、不改回测计算、不重画图表。

## 九项需求及功能方案

| ID / 优先级 | 当前问题 | 功能与用户流程 | 验收条件 |
|---|---|---|---|
| L1 / P0 个人计划 | 固定路线不能回答今天该投入多少、以什么为目标 | 选择基础理解 / 因子实践 / 研究验证，设置每次 10/20/40 分钟、每周 3/5/7 天，可绑定书架书籍 | 保存重启后保留；改目标不清除作答与手记；不把计划时间当成实际学习时间 |
| L2 / P0 今日任务 | 读书、复习和研究入口分散 | 按目标与时间预算组合少量建议：优先错题或概念练习，绑定书籍阅读，再做研究；已有到期闪卡优先复用 | 每项直达对应页面；根据真实作答、手记和既有进度刷新；无数据也有明确起点 |
| L3 / P0 知识地图 | 书中术语缺少跨章节查阅与先修关系 | 8 个核心概念，中英文搜索、收藏、先修导航、定义、公式口径、手算例子、常见误解，连接内置教材原文 | 所有引用可到实际章节；搜索无结果可恢复；浏览本身不标记掌握 |
| L4 / P0 基础诊断 | A 股规则测验不覆盖因子研究基础 | 16 道原创量化题，诊断与单概念练习；提交后展示答案及推导 | 提交前不泄题；每题只记一次；按每道题最近作答形成概念状态 |
| L5 / P0 错题再练 | 没有客观的量化错题反馈闭环 | 最近答错的题自动加入错题集，可查看概念后重做 | 新一次答对移出待练，历史记录保留；空错题集不伪装成已完成一轮 |
| L6 / P0 研究手记 | 普通章节小结缺少可证伪假设和实验记录 | 新建 / 编辑 / 删除手记，记录假设、验证方法、观察证据、结论、下一步；可关联概念与任意书籍小节 | 保存后可恢复；保留来源标题快照；原书删除不删研究；未保存返回有保护 |
| L7 / P1 实验质量检查 | 容易把漂亮回测当成有效策略 | 在手记中逐项写明信息时点、历史股票池、成本、样本外四项检查依据 | 只有填写证据才计入已记录；标识为自查，不宣称系统验证过实验；缺项可继续保存草稿 |
| L8 / P1 AI 陪练 | 直接看答案难以暴露理解盲点 | 概念页 / 手记页准备可编辑陪练问题，预览所附材料，明确点发送后进入独立通用对话；逐问追问、要求反例和证据 | 不自动调用模型；未配置可去配置；不覆盖忙碌会话；只附当前选中材料，不带整本书或其他手记 |
| L9 / P1 学习周报与导出 | 缺少能带到电脑继续研究的学习证据 | 本周活跃天数、作答正确率、概念薄弱项、研究新增量；导出周报和手记为 Markdown | 分母和日期范围清楚；零作答显示暂无；历史作答不会被重做覆盖；系统分享取消不声称已保存 |

## 交互方案

研习首页按「今天做什么 → 我的工具 → 本周进展」排序。首次显示默认可用计划和一次基础诊断。建议任务给出内容与预计分钟数；完成后重新计算下一步，不提供虚假打卡按钮。知识地图是可搜索、可筛选的纵向列表，详细页以概念、例子、误区、练习和教材出处组织。测验是一题一屏，先选、再提交、看反馈、下一题；中断保留已提交题的学习证据。

研究表单采用分段纵向输入，空内容可作为草稿，但必须填写标题与假设；较长内容随系统字体扩展。来源从真实书架和可读小节选择，查看原文时再确认来源存在。AI 陪练先呈现问题与材料，用户可以修改问题后发送。学习报告不与投资收益、交易胜率混淆。

## 研发技术方案

- **数据层**：SQLite 迁移 0011 新增计划、概念收藏、追加式作答、研究手记四张表。既有表仅被读取；迁移和版本号同一事务。作答 `(run_id, question_id)` 唯一，防重复提交。手记来源使用标题快照而非级联外键，避免删书时丢失研究。
- **领域层**：`src/learning/` 放置类型、内容目录、建议任务、诊断组题、最近答案聚合、周报和 AI 陪练材料。纯函数接收明确日期，学习日使用设备本地日历；行情仍沿用原有北京时间。
- **仓储层**：`src/data/learningRepo.ts` 负责校验、事务、持久化与读取。计划改变只更新计划；作答永不重写历史；研究更新保持创建时间。
- **界面层**：`src/ui/learning/` 放置共享样式/组件、研习首页、计划、知识、测验、手记、陪练与报告。只在学习分段和根路由注册处接入；不修改 Claude 的文件。
- **复用**：书架 / 小节 / 阅读进度来自 bookRepo 与 studyRepo；到期闪卡复用 ReviewRun；AI 复用 `newThread` / `ask` / `useChat`；文件导出复用 `exportText`，无新增依赖。
- **并发与失败**：提交操作有同步锁与 disabled 状态；数据库错误保留输入并允许重试；加载失败有重试入口；异步加载忽略卸载结果；切换来源清除旧小节；源书丢失时明确提示并保留文本快照。
- **验证**：重点验证迁移升级保留旧内容、重复作答、错题订正、目标切换、日期边界、周报分母、手记来源与删除、AI 预览/发送边界；运行 lint、TypeScript、全量 Jest、Android 打包及独立模拟器关键路径。

## 本轮不包含

自动交易、实时投资建议、Python 在线执行、自动生成题库、云同步，以及 Claude 正在实现的图表讲解与可读性改版。内置概念和试题为原创学习内容；研究检查记录的是用户填写的依据，不替代实验执行。
