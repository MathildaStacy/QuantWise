# 因读 · QuantWise v1.1.4 · 修复 PDF 上传卡住

修复 PDF 上传中断后，解析页长时间停在“排队中 / 上传中”的问题。此前只要申请过上传任务，恢复时就会持续查询结果，即使云端还没有收到文件。

## 本次更新

- 恢复解析时先核对云端状态，为未收到的分片重新申请地址并补传；已接收的分片继续解析，已完成的分片保留。
- 补传后只处理对应批次的结果，避免旧批次的等待上传记录覆盖新任务。
- 分别显示等待上传、上传中、已上传待确认、云端排队、解析中和生成结果；解析页数不再被通用文案覆盖。
- 上传完成后，云端持续约两分钟未确认收到文件时暂停，显示原因并提供“继续”补传入口。
- 上传期间提示保持 App 在前台；暂停后将“上传中”改为“上传未完成”。

## 安装与升级

下载附件 `QuantWise-v1.1.4-arm64.apk` 直接覆盖安装。包名 `com.quantwise`、versionCode `8`、versionName `1.1.4`，沿用现有签名，保留书籍、学习记录、笔记和模拟账户，无需卸载或删除书籍。

升级后重新进入卡住书籍的解析页，App 会核对云端并补传未收到的分片。出现暂停提示时，检查网络后点“继续”。上传期间保持 App 在前台。

## 验证

- 全量测试：62 个测试套件、759 项测试通过；10 项需额外环境的测试跳过。
- 回归覆盖中断后重启、部分上传成功、上传响应丢失但云端已接收、旧批次隔离、云端状态与解析页数显示、等待确认超时及继续补传。
- TypeScript 类型检查和 ESLint 通过；ESLint 保留两条既有测试文件警告。
- Android arm64 Release 构建、版本及签名核验通过；安装包附带 `SHA256SUMS.txt`。

此次恢复逻辑通过可控的文件与服务客户端验证，未重新上传整本书进行云端端到端测试。超过 200 页的书仍按页码范围提交，每片都会上传整份 PDF；iOS 版本号同步，本次发布 Android 安装包。
