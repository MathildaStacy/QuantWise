# 因读 · QuantWise v1.1.2 · 阅读与原页核对

改善 PDF 导入后的实际阅读体验，让读者能从正文和 AI 引用直接核对本地原页。

## 本次更新

- 新增本地 PDF 原页查看器：节首、段落菜单和引用预览均可进入，支持物理页码跳转、前后翻页、100–400% 放大、90° 旋转和双向拖动。
- 后台解析完成或暂停时自动刷新书架状态。
- 保留 Part 下没有自身正文的章标题，改进目录缩进、长标题和大字号显示，修复搜索框文字裁切。
- 正确处理普通段落中的 HTML 脚注、上下标；复杂行内公式交给离线 MathJax，未知命令不再静默变成错误变量。
- 伴读发现符号矛盾或乱码时，区分解析文本与自己的推算，引导查看 PDF，不直接归因于作者错误。

## 版本与兼容性

代码标签 `v1.1.2`；Android versionCode `6`、versionName `1.1.2`，iOS 项目版本同步为 `6` / `1.1.2`。沿用现有包名、签名和数据库，不重建已有书籍、学习记录或引用。

本次交付 main 与版本标签；标签本身不自动发布 GitHub Release 或 APK 附件。已发布安装包仍可从 v1.1.1 Release 下载。

## 验证与限制

- 62 个套件、753 项测试通过，包含六本真实 PDF 的本地解析结果回放；TypeScript 通过，ESLint 无错误、2 条原有警告。4 项既有 AI live 测试跳过。
- 独立 Android 设备完成六本书阅读、8 张兜底原页、150% 字号和引用跳转检查；7 次真实伴读请求，基线 25 个去重引用指向已加载内容。
- Android arm64 Release 构建通过；APK 版本核验为 `1.1.2` / `6`，签名验证通过。
- 旧解析中的负号、变量、公式编号、跨页页码、索引串栏和部分模型说明污染仍需内容修复。原页查看与排版改进不等于修复 OCR；未逐字校对全书。
- iOS 本次未专项验证。
