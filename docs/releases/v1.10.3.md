# 因读 · QuantWise v1.10.3 · 取全后重做，上一问的准备卡不再留着

讲解里中证 1000 没取全时，结果下面有「接着取数据并重做这次检验」。取全以后讲解会自动用全部成分重做，可前面那一问「中证 1000 还没取全」的卡和按钮还留着，排在新结果上面，像是还要再取。这一版的准备卡只跟着最近一次因子检验：后面又成功跑过因子检验，前面那问的卡就不再出。自动重做那一问里池子名和后面的字之间缺的空格也补上了。v1.10.2 的盘中准备这次在真实交易时段里验收过，结果写在下面。

## 本次更新

- **准备卡只跟着最近一次因子检验**：后面一问成功跑过 `factor_test`（取全后自动重做，或者换了股票池重算），前面那问的「准备数据」「接着取数据」「更新数据」卡就不再出。中间只聊别的、只取因子值，或者检验报错，卡都还在。重做时如果还是随机样本，卡挪到重做的那一问下面，始终只有一张。
- **自动重做那一问补上空格**：现在写成「数据准备好了：用中证 1000 重做这次检验」「中证 1000 的数据准备好了」，以前「1000」和后面的汉字连在一起。已经发出去的问题不改。

## v1.10.2 的盘中验收（2026-11-06 交易时段）

v1.10.2 发布时只在测试里用假时钟走过盘中准备，这次在真实交易时段里补了验收：

- **电脑上（10:40）**：用 App 的取数代码直连真实接口。东方财富、腾讯回的最后一根都是当天（11-06，没收盘），存下的只到 11-05，库里晚于 11-05 的是 0 行；盘中再准备一次，一个请求也没多发。
- **模拟器上（v1.10.2）**：中证 1000 从 515 只接着取到 1000 / 1000，用了约 6.5 分钟、536 次请求、约 25 MB（东方财富，平均每只约 1.1 次）。讲解随后用全部 1000 只成分自动重做了 3.5.3 表 3.20 的检验：50 期，每期平均 924 只；等权多空每期 +0.26%（t 0.17），市值加权 −0.18%（t −0.11），IC −0.018（t −0.61）。因子实验室里的中证 1000 显示「1000 只当前成分 · 61 期 · 2021-09-24 至 2026-10-14」，没有出准备卡。
- 这一轮发现了本版修的两处界面问题。
- 未覆盖：收盘后（15:30 以后）在真实行情下把当天那根取回来，仍只在测试里用假时钟走过。

## 已知限制

- 卡只看讲解记录，不看本机数据现在齐不齐：一问说要准备，之后没再跑过因子检验，就算已经在因子实验室取全了，卡也还在。点了只补过期的，很快就会重做。
- 以前自动发出的「数据准备好了：用中证 1000重做这次检验」在讲解记录里照原样显示。
- 东方财富和腾讯仍会限流，中证 500、中证 1000 可能要分几次才能取全，和 v1.10.1 一样。
