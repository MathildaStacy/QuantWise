# 因读 · QuantWise v1.0.0

**读懂因子，看懂市场。** 这是因读的首个正式 Android 版本，汇集此前 QuantWise 预发布版的读书伴学、行情与因子工具、模拟交易能力，并统一 App 和工程名称。

## 主要功能

- **导入与读书**：导入 Markdown、EPUB 和 PDF（MinerU），内置《因子投资入门》示例教材；按章节重排阅读，支持公式、表格、高亮和原文引用。
- **AI 伴读**：逐节讲解、检查题、岔路问答、本节小结和闪卡；引用可回到原文，讲解可以用真实 A 股行情画图举例。
- **因子实验室**：支持 7 个因子、示例池 / 自选与持仓 / 沪深 300 当前成分，计算分组回测、Rank IC、换手和成本后的收益。
- **复习与笔记**：Leitner 闪卡复习、卡点记录，导出 Markdown 笔记和 Anki CSV。
- **模拟交易**：保留 AShareSim 的行情、自选、模拟账户、交易规则与税费、组合调仓、回放和全局 AI 助手。

## 本次更新

- App 桌面名称改为 **因读**，启动页和「我的」展示 **因读 · QuantWise**；同步后台通知、省电引导、原型和文档中的名称。
- iOS 工程、scheme、Podfile 和 CI 配置统一为 QuantWise；Android 包名仍为 `com.quantwise`。
- 包含预发布阶段已修复的 MinerU 行内公式多余空格、图表标签被曲线或柱形遮挡问题。
- 版本升级到 `1.0.0`，Android versionCode 为 `3`。

## 安装与升级

下载本页附件 **`QuantWise-v1.0.0-arm64.apk`**，在 Android 手机上打开安装。此包仅包含 `arm64-v8a` 架构。

已有 QuantWise v0.1.0 / v0.1.1 时，直接覆盖安装即可。包名和签名沿用原版本，无数据库迁移，可保留书籍、学习进度、笔记、模拟账户和服务配置；无需先卸载。

首次使用时，在「我的 → 供应商与模型」配置自己的 AI 服务；导入 PDF 还需在「我的 → 解析服务（MinerU）」配置 Token。`SHA256SUMS.txt` 可用于核对安装包。

## 已知限制

- 本次仅发布 Android，iOS 尚未完成编译和运行验证。
- PDF 使用重排阅读，不显示原版页；单文件上限 200 MB，OCR 仍可能识错或漏字，导入书籍暂不支持改名。
- 因子数据最多 750 根前复权日线；沪深 300 使用当前成分，存在幸存者偏差，小市值和低换手因子使用当前股本近似。
