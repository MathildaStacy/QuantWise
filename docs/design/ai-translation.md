# AI 逐句对照翻译

## 产品方案

面向阅读外文量化教材的读者，在「读书」页直接核对原句和简体中文译文。用户已确认只需要简体中文。按语义句分行，长句随屏幕换行，不按 PDF 的印刷行机械切分。

- 读书页顶部提供「原文 / 中文对照 / AI 讲解」单层切换。进入页面或打开对照不自动调用 AI；点「翻译本节」或段落菜单「翻译这一段」才开始。已翻译内容可离线阅读。
- 每句原文下方紧跟中文译文，原文沿用宋体、译文使用系统黑体与次级文字色。沿用暖白阅读底色、墨蓝操作色、48dp 触摸目标，窄屏和系统大字号自然换行。
- 支持正文、列表与图注；纯中文段落不必重复翻译，独立公式、代码、表格和原页图像保持原样。行内公式和数字需原样保留；原文始终来自本地书籍。
- 显示已完成段数，运行时可停止；失败显示原因和重试入口，缺少模型/Key 提供配置入口。完整段落立即保存；继续只处理缺失内容。切换小节、离开页面、关闭对照会停止当前请求。
- 翻译复用现有供应商与当前模型，独立于 AI 讲解会话，不推进教学进度。不默认联网搜索或调用工具。只发送当前待译段落及书名、节名上下文。

## 研发方案

本地先切句并分配稳定 ID，模型只返回 ID 与译文。校验缺句、重复、未知 ID、空译文、数字与公式变动；通过后按本地原文顺序展示，模型不能重写原文或改变引用编号。每次请求限制句数与字符量，大段分批串行处理。屏幕朗读按句读出完整原文及对应译文。

SQLite 新增 `book_translation`，以书、内容块及目标语言为键，记录原文、逐句译文、模型及生成时间。复用时核对原文和句划分；原文变化自动失效。外键关联内容块，删书或重新解析时自动清理。只缓存完整、通过校验的段落，停止不会保存半截 JSON。

对照开关按书与小节保存在阅读状态。保留原块的布局锚点、段落菜单、高亮、PDF 原页及引用定位；译文扩展高度时保持当前可见段落。

## 验收

1. 英文多句、缩写、小数、列表、行内公式与长段切句不丢失原文；返回乱序仍正确对齐。
2. Anthropic Messages、OpenAI Responses、Chat Completions 均经过现有协议层；翻译不创建讲解消息或推进进度。
3. 首次翻译、缓存复用、断网、停止、继续、缺 Key、错误响应、切节与重进均有确定行为。
4. 原文改动后不复用旧译文；删除书籍清理缓存；旧数据库可升级。
5. Android 手机正常字号、放大字号及系统深色设置下可读，操作可达；全量 lint、类型检查、Jest、Android Release 构建通过后合 main，发布 v1.2.0 与 APK。
